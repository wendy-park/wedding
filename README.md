# 💍 석익준 ♥ 박규리 모바일 청첩장 웹사이트 안내서

스튜디오 수정본 사진이 나오면 **언제든지 사진만 바로 업데이트**할 수 있도록 완벽하게 제작된 모바일 청첩장 웹사이트 패키지입니다.

---

## 📂 파일 구성

```text
wedding-invitation/
├── index.html        # 청첩장 메인 페이지 (반응형 모바일 최적화 레이아웃)
├── style.css         # 고급 에디토리얼 웨딩 스타일 (폰트, 컬러, 애니메이션)
├── script.js         # D-Day 카운트다운, 갤러리 라이트박스, 계좌복사, 실시간 사진 교체
├── config.js         # ⭐️ 예식 일시, 장소, 신랑/신부 정보, 계좌번호 등 간편 설정 파일
├── README.md         # 본 안내서
└── images/           # 청첩장에 들어가는 사진 폴더
    ├── cover.jpg     # 메인 커버 사진 (수정본 대표 사진)
    └── gallery-1.jpg ~ gallery-8.jpg  # 갤러리 사진 8장
```

---

## 📸 수정본 사진 나오면 바로 업데이트하는 방법 (2가지)

### 방법 1. 웹 화면에서 실시간으로 직접 올리기 (가장 간편!)
1. 브라우저에서 `index.html`을 열면 우측 상단에 **[📷 사진 실시간 업데이트]** 플로팅 버튼이 있습니다.
2. 버튼을 누르면 사진 관리 창이 열립니다.
3. 메인 커버 사진과 갤러리 1~8번 사진에서 **[사진 선택하기 / 교체]**를 눌러 스튜디오 수정본 사진을 고릅니다.
4. 선택하는 즉시 화면에 실시간으로 적용되어 청첩장 모습을 바로 확인하실 수 있습니다.
5. **[✨ 변경사항 화면에 반영하기]**를 누르면 브라우저에 저장되어 새로고침 후에도 유지됩니다.

### 방법 2. `images/` 폴더에 파일 덮어쓰기 (배포용 추천)
1. 스튜디오에서 받은 수정본 사진 파일의 이름을 아래와 같이 변경합니다:
   - 메인 사진 ➔ `cover.jpg`
   - 갤러리 사진들 ➔ `gallery-1.jpg`, `gallery-2.jpg`, ..., `gallery-8.jpg`
2. `wedding-invitation/images/` 폴더에 그대로 복사하여 덮어쓰기만 하면 코드 수정 없이 사이트 전체에 자동 반영됩니다!

---

## ✏️ 예식 정보 & 계좌번호 수정 방법

`config.js` 파일을 열면 상단에서 바로 필요한 정보를 수정하실 수 있습니다:
- **신랑/신부/혼주 연락처 및 성함**
- **축의금 계좌번호 및 은행명**
- **모시는 글(초대 인사말 문구)**

---

## 🌐 하객 전달용 무료 웹 배포 방법

실제 하객들에게 카카오톡 등으로 모바일 청첩장 링크를 공유하려면 웹에 배포(호스팅)해야 합니다.
1. **GitHub Pages** (무료, 평생 유지): 리포지토리에 올리고 Settings > Pages에서 클릭 한 번으로 `https://username.github.io/wedding` 주소 생성
2. **Vercel / Netlify** (무료, 30초 배포): 폴더를 드래그앤드롭하면 즉시 링크 생성

> 💡 **피클에게 맡기기**: 사진을 전달해 주시거나 깃허브 계정 연동을 해주시면, 제가 도메인 배포 및 모바일 청첩장 링크 생성까지 전부 대신 완료해 드릴 수 있습니다!
